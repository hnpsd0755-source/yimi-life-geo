建议浏览顺序

  1. 首页：能否快速理解公司定位、主要产品及合作方式。
  2. 产品总览：品类、图片、说明和入口是否清楚。
  3. 血氧仪选型：点击 Prime 等款式，确认第一个型号自动选中，照片与规格随即展开；再切换其他型号、查看图片与询盘入口。
  4. 血压计：检查型号差异、规格可读性与询盘路径。
  5. 公司与研发、制造与质量：评价真实素材、能力说明和文档展示。
  6. OEM/ODM、Contact：体验定制介绍和表单交互。
