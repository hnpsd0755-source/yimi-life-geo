## Local preview and publication

From the repository root:

```powershell
node docs/design/website-templates-20260910/serve.cjs 18767
```

Open http://127.0.0.1:18767/?page=home .

Build the static publication:

```powershell
node docs/design/website-templates-20260910/export-static-preview.cjs
```

The exporter validates website references and copies runtime pages, CSS, JavaScript and their images/PDFs into the ignored `dist` directory. It excludes source archives, office documents, CJS tools and Markdown notes.
Vercel should use repository `hnpsd0755-source/yimi-life-geo`, branch `main`, root `docs/design/website-templates-20260910`, framework Other, no install command, and this directory's `vercel.json`.
The site keeps `X-Robots-Tag: noindex, nofollow` for the review phase.

## Continue on another computer

Fetch GitHub and fast-forward `main` only after checking for local edits. Do not discard local changes.
The static preview and publication commands require Node.js only; no dependency installation is needed for these templates.
For Next.js work, use the repository's existing dependencies and commands separately.
Keep raw archives, source spreadsheets, Word documents and temporary review captures outside the publication commit.
