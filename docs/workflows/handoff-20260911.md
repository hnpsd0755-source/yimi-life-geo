## 已确定的主要方向

- B2B 海外品牌、渠道与 OEM/ODM 买家优先。先确定页面内容，再做 UI 模板，真实资料和图片后填。
- 首页主体：产品 → 公司 → 研发 → 工厂 → OEM 合作案例。客户反馈需要真实依据，不能编造客户原话。
- 五大产品类别：Pulse Oximeter、Blood Pressure Monitor、Wearable Monitoring Devices、雾化器、体温计。
- 雾化器：压缩雾化器、手持微网雾化器。体温计：红外额温枪、体温贴、快速温度计。新增类别最终英文、型号、参数和正式地址仍待确定；体温贴主分类归体温计。
- 主导航不设独立 Technology。PulseMatrix™ 只作为血氧产品的技术详情子页；low-perfusion、motion-artifact-rejection、skin-tone-fairness 是同一页中的三个方向或参数，不拆成三个专题。正式英文声明、测试条件与适用型号需核实，不能从模板推断性能结论。
- 公司与研发可以展示团队、实验室、专利；注册证书与产品/质量证据关联，Fluke 按实际测试用途介绍。
- 每次设计变化先研究需求、当前页面和相关竞品，再提出有依据的方案；按用户已有授权实施。该流程已同步到项目技能。

## 在其他电脑打开

首次取得项目：

```bash
git clone https://github.com/hnpsd0755-source/yimi-life-geo.git
cd yimi-life-geo
```

若已有项目，先检查 `git status --short`、`git branch --show-current` 和 `git remote -v`。只有确认当前为 `main`、远程正确且工作区干净时，执行：

```bash
git fetch origin
git merge --ff-only origin/main
```

如有未提交修改、未跟踪文件或分支异常，先停止并检查，不自动 stash、commit、rebase、reset 或普通 pull。此前办公室电脑保留的五项本地资料不应推断为其他电脑也可自动忽略；需核对具体情况。

仅查看本轮新 UI，需要 Node.js，无需安装项目依赖：

```bash
node docs/design/website-templates-20260910/serve.cjs
```

打开 http://127.0.0.1:8767/ ，OEM/ODM 为 http://127.0.0.1:8767/?page=oem 。这次办公室验证使用 8768，以保留原 8767 会话；另一台电脑默认使用 8767。

运行现有正式网站代码，首次先安装锁定依赖，再启动：

```bash
npm ci
npm run dev
```

打开 http://localhost:3000/ 。后续仅在依赖缺失或锁文件变化时重新安装。独立预览和 Next.js 网站是两个不同入口。
