# UI/UX Checklist

## Page Structure

- One clear H1 per page.
- Heading levels progress logically.
- Sections have consistent vertical rhythm.
- Similar sections use similar max width, padding, and spacing.

## Cards and Content Blocks

- Cards in the same row have consistent height.
- Card text length does not break rhythm.
- Repeated cards use consistent padding, border, radius, and hover behavior.
- Avoid nested card styling unless the component already uses that pattern.

## CTAs

- Primary and secondary CTA styles are consistent across the page.
- CTA labels are B2B-action oriented and not consumer-advertising style.
- CTAs remain readable and tappable on mobile.

## Product Tables and Modals

- Specification modal/table remains 2 columns on mobile and desktop when required.
- Use 40% / 60% grid columns where applicable.
- Table header blue uses `#08A8AE` where applicable.
- Avoid overloading tables with broad compliance or marketing content.

## Responsive Checks

- No overlapping text.
- No clipped buttons.
- No awkward line breaks in compact cards.
- Mobile spacing remains readable without excessive vertical bloat.
- Desktop sections do not look sparse or patchwork.
