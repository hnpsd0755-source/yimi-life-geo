# YimiLife UI/UX Page Review

If this skill conflicts with repository AGENTS.md, follow AGENTS.md first.

Use this skill when reviewing or editing YimiLife page UI, section layout, product pages, modal tables, cards, CTAs, responsive behavior, or design consistency.

## Checklist

Use `references/uiux-checklist.md` and report only actionable issues.

## Required Review Areas

- Heading hierarchy.
- Section rhythm.
- Card height consistency.
- Card spacing.
- CTA style consistency.
- Mobile and desktop layout.
- Product specification modal and table consistency.
- Standard blue `#08A8AE` usage when applicable.
- Avoid template-like or patchwork design.
- Do not redesign unrelated pages.

## Editing Rules

- Keep changes minimal and page-scoped.
- Preserve the existing design language.
- Do not introduce new UI libraries or icon libraries.
- Avoid unrelated layout rewrites.
- Verify visually when UI changes are made and a local preview is available.

## Output Format

For review:

- Finding.
- Location.
- Why it matters.
- Suggested minimal fix.

For edits:

- Files changed.
- Visual behavior changed.
- Desktop and mobile checks performed or not performed.
