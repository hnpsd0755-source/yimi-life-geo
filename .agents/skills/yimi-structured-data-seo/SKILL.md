# YimiLife Structured Data SEO

If this skill conflicts with repository AGENTS.md, follow AGENTS.md first.

Use this skill for metadata and structured data review or edits on YimiLife pages.

## Required Checks

- Title.
- Description.
- Canonical URL if present.
- Open Graph fields.
- H1 uniqueness.
- Image alt text.
- Internal links.
- Product schema if present.
- Organization schema if present.
- Breadcrumb schema if present.

## Structured Data Rules

- Structured data must be supported by visible page content or confirmed business facts.
- Do not invent certification status, approval status, clinical validation, product availability, launch status, aggregate ratings, reviews, awards, customer names, or pricing.
- Product schema should be restrained and factual.
- Organization schema should use confirmed YimiLife business identity only.
- Breadcrumb schema should match the actual route hierarchy.

## Metadata Style

- Write for B2B medical device procurement intent.
- Include important keywords naturally.
- Avoid keyword stuffing.
- Avoid consumer-style performance claims.
- Keep descriptions specific enough for search snippets and AI summaries.

## Output Format

Provide:

- Field or schema reviewed.
- Issue found, if any.
- Minimal recommended change.
- Whether confirmation is required.
