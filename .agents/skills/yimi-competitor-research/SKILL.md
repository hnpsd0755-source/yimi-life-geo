# YimiLife Competitor Research

If this skill conflicts with repository AGENTS.md, follow AGENTS.md first.

Use this skill for competitor website analysis and market positioning research related to YimiLife.

## Source Rules

- Do not invent competitor claims.
- If live browsing is unavailable, ask for competitor URLs, screenshots, exported HTML, PDFs, or notes.
- Clearly distinguish observed facts from interpretation.
- Cite URLs or provided source files when possible.

## Analysis Areas

Use `references/competitor-analysis-framework.md`.

Review:

- Hero positioning.
- Product architecture.
- OEM/ODM capability expression.
- Compliance and certification expression.
- CTA strategy.
- Page conversion flow.
- Visual style.
- Content gaps and opportunities.

## Output Direction

Recommendations must be actionable for the YimiLife website only.

Do not recommend:

- Unsupported medical claims.
- Invented certification or clinical validation.
- Consumer-style exaggeration.
- Broad redesigns unrelated to the analyzed issue.

## Output Format

Provide:

- Competitor observed pattern.
- Implication for B2B buyers.
- Opportunity for YimiLife.
- Recommended website action.
- Required confirmation, if any.
