# Medical Copy Risk Terms

## Avoid Without Explicit Confirmation

| Risky wording | Main risk | Safer direction |
| --- | --- | --- |
| FDA approved | Approval status may be inaccurate for many device classes | FDA / MDR / NMPA certified models, if supported |
| Clinically proven | Requires evidence and scope | Evaluated through defined validation or calibration workflow, if supported |
| Guaranteed accuracy | Absolute performance claim | Designed for consistent measurement performance |
| Diagnose disease | Diagnostic claim | Supports measurement, monitoring, or screening workflows, if supported |
| Prevent SIDS | High-risk infant safety claim | Avoid unless legally reviewed and fully substantiated |
| 100% reliable | Absolute reliability claim | Built for stable operation under defined use conditions |
| Zero bias | Absolute fairness claim | Use restrained PulseMatrix™ terminology only when supported by approved website wording |
| Guaranteed accuracy | Absolute accuracy claim | Discuss manufacturing, calibration, or configuration review only when supported |
| Clinically proven fairness | Clinical and fairness claim requiring supporting evidence | Avoid unless supporting validation evidence is explicitly provided and approved |
| Anti-motion | Unapproved public-facing PulseMatrix™ anchor | Use motion conditions |
| Motion-proof | Absolute motion claim | Use performance under motion conditions |
| Eliminates motion artifacts | Absolute artifact-removal claim | Use performance under motion conditions |
| Skin tone fairness signal design | Deprecated public website wording | Use SpO₂ performance across diverse skin pigmentation |
| Non-disparate performance across diverse skin pigmentation | Validation-sensitive claim | Use only if supporting validation evidence is explicitly provided and approved |
| Hospital-grade diagnosis | Diagnostic and grade claim | Suitable for professional procurement evaluation, if supported |
| Cure, treat, prevent disease | Treatment or prevention claim | Avoid for website marketing copy |

## Topics Requiring Confirmation

- FDA / MDR / NMPA status.
- Clinical validation.
- Infant monitoring.
- Disease diagnosis.
- Remote healthcare claims.
- AI medical advice.
- Algorithm accuracy.
- SpO₂ performance across diverse skin pigmentation.
- Continuous blood pressure.
- Vascular stiffness index or other advanced physiological indicators.

## PulseMatrix™ Fixed Website Terminology

PulseMatrix™ has only three confirmed public website directions. Treat these as signal-platform directions, not as absolute clinical performance claims.

1. PI 0.1% 低灌注
   - Primary English anchor: PI 0.1% low-perfusion.
   - Formal wording: performance under PI 0.1% low-perfusion conditions.
2. 抗运动
   - Primary English anchor: motion conditions.
   - Formal wording: performance under motion conditions.
3. 不同肤色表现一致性
   - Primary English anchor: across diverse skin pigmentation.
   - Formal wording: SpO₂ performance across diverse skin pigmentation.

## PulseMatrix™ Compliance Rules

- Do not replace these fixed anchors with alternative public-facing terminology unless the user explicitly confirms a terminology update.
- Do not use “anti-motion” as the primary public-facing anchor.
- Do not use “motion-proof”.
- Do not use “eliminates motion artifacts”.
- Do not imply the device remains accurate under all motion conditions.
- Do not use “skin tone fairness signal design” as public website copy.
- Do not use “zero bias”.
- Do not use “guaranteed accuracy”.
- Do not use “clinically proven fairness”.
- Do not imply universal accuracy across all skin tones.
- Do not claim “non-disparate performance across diverse skin pigmentation” unless supporting validation evidence is explicitly provided and approved.
- Do not expand PulseMatrix™ beyond these three confirmed directions.
