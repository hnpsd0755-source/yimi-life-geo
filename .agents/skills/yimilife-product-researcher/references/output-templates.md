# Output Templates

## Product Opportunity Brief

Use this structure when the user asks whether a new product is worth doing.

1. Executive recommendation
   - Verdict: Go / Hold / No-Go
   - Confidence: High / Medium / Low
   - Why now
   - Biggest risk

2. Target user and scenario
   - Primary user
   - Purchase trigger
   - Usage context
   - Current workaround

3. Problem and insight
   - Core pain point
   - Evidence
   - Emotional driver
   - Functional driver

4. Competitor landscape
   - Main competitors
   - Price range
   - Common features
   - Customer complaints
   - Gaps YIMILIFE can exploit

5. Product definition
   - Product promise
   - MVP feature set
   - Nice-to-have features
   - Features to avoid in v1
   - Key specs or constraints

6. Differentiation
   - Design differentiation
   - Functional differentiation
   - Brand or trust differentiation
   - Channel differentiation

7. Validation plan
   - Landing page test
   - Review mining
   - Prototype test
   - Supplier/engineering feasibility check
   - Success threshold

8. Next actions
   - 3 immediate tasks
   - Open questions
   - Decision checkpoint

## Competitor Matrix Columns

Use these columns by default:

- Brand/Product
- Link
- Price
- Target user
- Core features
- Differentiator
- Review rating or visible demand signal
- Repeated complaints
- Opportunity gap
- Notes for YIMILIFE

## PRD Input

Use this structure when the user wants product definition output.

- Product goal
- Non-goals
- Target users
- Core use cases
- User stories
- Functional requirements
- Industrial design or UX requirements
- Performance/spec requirements
- Packaging/accessory requirements
- MVP scope
- Future versions
- Risks and dependencies
- Acceptance criteria

## Website Positioning Input

Use this structure when product research feeds the company website or product page.

- Product category
- One-line positioning
- Hero headline options
- Subheadline
- Primary CTA
- Feature hierarchy
- Proof points
- Comparison angle
- FAQ
- SEO keyword themes
